# Absentplays — Creator & Community Hub


A lightweight, personal landing page and creator dashboard for **Absentplays**. Built as a single-page frontend application to display social links, active Discord server communities, and affiliated partnerships.

> **Note**: This repository is intended strictly for personal use and maintenance.
> 
> 

---

## Overview & Features

* **Cosmic Theme UI**: Features a custom space background gradient, a floating stars canvas effect, and responsive glassmorphism card layouts (`backdrop-filter`).
* **Social Media Directory**: Direct access points for Twitter/X (`@absentplays`), Twitch (`absentplays`), and Discord profile details.
* **Community Hub Cards**: Visual links to managed Discord servers:
* **Absent Services**: Showcases Minecraft support, Discord assistance, and active projects.
* **AbsentDiscordTemps**: Highlights free Discord templates and custom request services.
* **Partner Integration**: Showcases active affiliate links and partnerships (such as Physgun).


---

## Tech Stack

* **HTML5**: Page structure and semantic layout.
* **CSS3**: Layout styling utilizing Flexbox, CSS Grid, custom gradients, and animations.
* **Font Awesome (v6.4.0)**: CDN-hosted icon suite for UI components.
